Files or folders are missing

  • Review StoragePilot's media permissions in Android Settings.
  • For documents or folders, use Android's file picker to select the location again.
  • Some system, app-private, and private messenger data is not available to ordinary storage apps.
  • Optional usage access shows Android-provided app storage totals; it does not provide access to private app files.

Compression did not finish

  • Keep enough free space for StoragePilot to create a new output before replacement.
  • Allow notifications if you want background compression progress.
  • If an operation fails, the original file should remain unchanged.
  • Try one file first and include the file type and approximate size when contacting support.

Delete, restore, and cleanup behavior

StoragePilot requires an explicit action before deleting or replacing a file. Android may display an additional confirmation. Recycle and restore behavior depends on the file type, location, Android version, and the permissions Android provides. Cleanup rules create suggestions only and do not delete files automatically.

Ads and privacy choices

The free version uses Google AdMob. Where required, Settings includes an Ad privacy choices option provided through Google's User Messaging Platform. After an active Pro entitlement is confirmed, StoragePilot makes no ad requests. See the Privacy Policy for details.

Pro purchase or restore issue

Confirm that Google Play is signed in with the account used for the purchase, then use StoragePilot's Restore purchase action. Store availability, billing, pending transactions, and refunds are handled by Google Play.
