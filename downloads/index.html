Windows 10 / 11 Self-signed sideload

Offline Vault Companion 1.0.1

Download one file and run it. This build is self-signed and untimestamped, so Windows may show a SmartScreen warning. It is not a Microsoft Store or generally trusted installer.

  1. Download and run the EXE. Open OfflineVaultCompanion-Setup-1.0.1.exe after it finishes downloading.
  2. Continue through SmartScreen. If Windows shows a warning, choose More info, then Run anyway.
  3. Approve the Windows prompt. Choose Yes when User Account Control asks for permission.
  4. Let setup finish. The installer securely installs the embedded GreenVital public certificate and app, then launches Offline Vault Companion.

Advanced / manual installation

Use these files only if you prefer to install the certificate and app package manually.

  1. Install the public certificate. Open the .cer, choose Local Machine, and place it in Trusted People.
  2. Verify the certificate. Confirm SHA-1 thumbprint FC677345547ACF903AC8ABBEEEBD79A30318889C.
  3. Open App Installer. Download the .appinstaller only after the certificate is trusted.

After installation

Connect your iPhone.

  1. Keep the computer and iPhone on the same local Wi-Fi network.
  2. Choose a media folder in the companion and select Start Sharing.
  3. On iPhone, open Transfers, scan the QR code, and approve the connection.
  4. Browse supported media and transfer the files you want available offline.

Changing the shared folder refreshes what the phone sees. Stopping sharing or closing the companion disconnects the phone.
